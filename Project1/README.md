# 🚀 StartUp AI
### Rule-Based Startup Assistant Chatbot

StartUp AI is a modern rule-based chatbot built using **Python Flask**, **HTML**, **CSS**, and **JavaScript**.  
The chatbot acts as a virtual startup assistant that helps users with startup-related topics such as:

- Hiring
- Marketing
- Funding
- Product Launch
- Business Growth
- Investors

This project was developed as part of the **Artificial Intelligence Internship Project 1** focused on building a **Rule-Based AI Chatbot** using conditional logic and control flow.

---

# 📌 Project Objective

The objective of this project is to create a chatbot that:

- Responds to predefined user inputs
- Uses if-else decision-making logic
- Handles greetings and exit commands
- Runs continuously through user interaction
- Simulates intelligent conversation using rule-based responses

Unlike AI-powered chatbots that use machine learning, this chatbot uses pure logical conditions to generate responses.

# 🧠 How the Chatbot Works

The chatbot uses rule-based programming.

Example:

```python
elif "marketing" in user_input:
    return "Digital marketing and social media campaigns are effective startup strategies."
```

The chatbot:
1. Receives user input
2. Converts it to lowercase
3. Matches keywords using if-else logic
4. Returns predefined responses
